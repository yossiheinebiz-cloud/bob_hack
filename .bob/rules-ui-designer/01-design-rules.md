# Rules — מעצב UI (ui-designer mode)

## לפני כל מסך — בדוק
1. האם המסך מוגדר ב-`05-screens-spec.md`? קרא את המפרט שלו קודם.
2. מה **פעולה אחת** שהמשתמש צריך לעשות במסך הזה?
3. מה **מספר אחד** שהמשתמש צריך לראות?

## כללי HTML/CSS מחייבים
```
dir="rtl" על כל <html>
font-family: system-ui, -apple-system, sans-serif
```

## מה לא לעשות בעיצוב
- לא Lorem Ipsum — תמיד נתונים עבריים אמיתיים
- לא אדום לממצאים רגילים — רק לסיכון גבוה
- לא יותר מפעולה אחת ראשית בכל מסך
- לא גרפים מורכבים — מספרים גדולים עדיפים על pie charts
- לא shadow כבד — border עדין (#2A2D3A) בלבד

## בדיקת RTL לפני סיום
- [ ] כל הטקסט מיושר ימין
- [ ] אייקונים של חץ "←" (שמאל) לניווט אחורה
- [ ] Flex rows הפוכים (flex-row-reverse) במקום הנכון
- [ ] טפסים: label מימין, input מתרחב שמאלה
